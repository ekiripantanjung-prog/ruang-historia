# Foto dan ilustrasi tambahan dari guru

Taruh foto atau ilustrasi di folder ini. Dalam 1–2 menit, gambar otomatis muncul di bagian **"Jejak sejarah"** pada bab yang sesuai di aplikasi Ruang Historia.

## Cara menambah gambar

1. Di halaman folder ini, klik **Add file → Upload files**.
2. Seret foto ke kotak unggah (boleh beberapa sekaligus). Format: JPG, PNG, atau WEBP.
3. Klik tombol hijau **Commit changes**.

## Aturan nama file (penting)

```
<ruang>-<nomor bab> <judul gambar>.jpg
```

| Ruang | Kode |
|---|---|
| Sejarah Indonesia | `indonesia` |
| Sejarah Dunia | `dunia` |
| Sejarah Kebudayaan Islam | `ski` |

Contoh:

- `indonesia-8 Pembacaan teks Proklamasi 17 Agustus 1945.jpg` → Sejarah Indonesia Bab 8
- `ski-8 Masjid Agung Demak tahun 1930-an.jpg` → SKI Bab 8
- `dunia-7 Peta Perang Dunia II di Asia -- Sumber buku paket kelas XI.jpg` → Sejarah Dunia Bab 7, dengan keterangan "Sumber buku paket kelas XI"

Tulisan setelah dua tanda minus (`--`) menjadi keterangan atau sumber di bawah gambar.

## Mengganti atau menghapus

- **Ganti judul:** buka filenya, klik ikon pensil, ubah namanya, lalu Commit changes.
- **Hapus:** buka filenya, klik ikon tempat sampah (⋯ → Delete file), lalu Commit changes.

Ukuran foto akan dikecilkan otomatis supaya aplikasi tetap ringan. Pastikan foto yang diunggah boleh dipakai untuk pembelajaran, dan tulis sumbernya bila ada.
